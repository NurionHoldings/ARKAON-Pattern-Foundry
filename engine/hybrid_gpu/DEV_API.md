# ARKAON GPU 관리자 승인·작업 대기열: 개발용 프로토타입

## 구현
- `dev_api.py`: FastAPI 개발용 작업 접수, 목록, 승인, 거절 API
- `policy.py`: 승인 상태, 공급자 고정, 비용 상한, 승인 만료 등 정책 코어
- Python 메모리 내 작업 목록 + 프로세스 내 잠금. **재시작 시 작업 기록이 사라짐.**
- 작업 디스패치·GPU 실행 API는 의도적으로 제공하지 않음.

## 안전 경계
이 API에는 실제 사용자 인증과 관리자 권한 검증이 **없습니다**. `admin_id` 문자열을 입력하는 것만으로 승인할 수 있어 보안상 실제 운영에 사용할 수 없습니다. 반드시 **127.0.0.1 로컬 개발 환경에서만 실행**하고, Netlify 또는 인터넷에 배포하지 마세요. 이 상태에서 실제 GPU 실행과 연결하면 안 됩니다.

## 개발 환경에서 시험
```bash
python -m pip install fastapi uvicorn
python -m uvicorn engine.hybrid_gpu.dev_api:app --host 127.0.0.1 --port 8765
```
`POST /jobs` 본문 예: `{"requester_id":"demo","provider":"local","estimated_cost_krw":"0"}`

## 운영 전 필수 후속 작업
1. 실제 서버 세션 인증 + 관리자 RBAC, 요청자/승인자 분리, CSRF
2. PostgreSQL 영속 작업·승인·감사 로그 및 트랜잭션 원자성
3. 중복 방지 키·취소·실패 재시도·동시성 검증
4. 아웃바운드 로컬 워커 등록 및 일회성 실행 권한
5. 임대 GPU 제공업체 어댑터와 비용 상한 검증
6. 실제 이미지/영상 생성 검증, 배포 승인 및 UI

현재 완료: **승인 정책과 로컬 API 프로토타입**. 미완료: **운영 가능한 승인 화면·실행 대기열·영상 제작**.
