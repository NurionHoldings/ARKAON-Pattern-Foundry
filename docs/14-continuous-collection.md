# 14. 부팅 연동 상시 정보수집

- 명세 ID: APF-CONTINUITY-001
- 상태: LOCKED DEFAULT

## 최상위 운용 원칙

PC 운영체제가 시작되면 ARKAON 수집 런타임을 자동 시작한다. 첫 수집은 지연 없이 수행하고,
기본 15분 간격으로 허가된 정보의 변경을 계속 확인한다. 애플리케이션 재시작 후에도 같은
정책을 복원한다.

## 기본 정책

- 외부 65%, 내부 35%의 분석용량을 사용한다.
- 공식 표준, 공식 문서, 라이선스가 확인된 오픈소스를 우선한다.
- Intent 관련성 0.30 미만 또는 이미 확인한 content hash는 심층수집하지 않는다.
- 기능 구현을 우선한다. 라이선스 명확성 0.80 미만 자료도 소유권, 명시적 허가, 퍼블릭
  도메인 또는 클린룸 추상화 근거가 있고 출처계보를 기록했으며 원본 코드를 복제하지 않은
  경우에는 독립 자산화 예외를 적용한다.
- 위 예외 근거가 없으면 참고자료로만 보관하고 재사용 자산으로 승격하지 않는다.
- 참고자료는 종착점이 아니다. `REFERENCE_COLLECTED → PRINCIPLE_ABSTRACTED →
  INDEPENDENT_IMPLEMENTATION → INDEPENDENTLY_VERIFIED → OWNED_ASSET` 순서로 자체기능을
  개발한다. 원본 표현·코드를 가져오지 않고 기능 목적, 실패조건, 인터페이스 원리만 추상화한다.
- 자체·고객 위임 자료는 명시적 권한이 있을 때만 수집한다.

## 절대 금지와 정지조건

개인정보, 자격증명, secret, 승인되지 않은 비공개 자료, robots/이용조건 위반 자료는 수집하지
않는다. 보안정책 해제, 권한 자가상승, 감사기록 삭제, 사용자 데이터 임의이전도 금지한다.
정책 위반 신호가 발견되면 해당 Source만 fail-closed로 중지하고 이유를 감사기록에 남긴다.

## 배포 경계

`config/collector.default.json`은 제품의 초기설정이다. 실제 PC 부팅 등록은 설치 프로그램이
운영체제의 정식 자동시작 기능을 사용해 수행하며, 사용자 계정 범위를 벗어난 권한상승이나
보안기능 비활성화를 요구해서는 안 된다.
