# 12개 자체 견본 → 비교 → 심화 편집

## 구현

`/services/brand-gallery.html`에서 사업 이름·업종·서비스·직접 쓴 문구를 입력하면 12개 자체 절차형 SVG와 명함 앞뒤 미리보기를 만든다. 기존 6개 구조에 잎·방향·계단·띠·창·방사형 구조를 더했다. 같은 색·회전·선 두께에서도 12개 심벌 구조가 다르다는 Node 검사를 둔다. 이는 전 세계 독창성·상표 등록 가능성의 증명이 아니다. AI 이미지 생성·외부 디자인 복제는 사용하지 않는다.

3~4개를 비교 목록에 담은 뒤 그중 하나를 고른다. 선택한 형태·4종 정보 배치·직접 쓴 문구·비교 후보를 기존 브랜드 편집기의 같은 project로 전달한다. 편집 후 저장·새 탭 재오픈·견본 화면 복귀 시 최신 소개·연락처를 보존한다. 선택 전까지 운영 게시하지 않는다. 저장 실패 시 입력과 선택을 유지하고 다시 시도할 수 있다.

기존 `/services/logo-card.html`의 6개 방향 기능은 유지한다. 확장된 형태로 저장한 초안을 불러오면 선택 표시를 위해 12개 목록을 보여준다. 기존 #123~#125 증거는 변경하지 않는다.

## 검증 및 한계

- Node: 12개 구조·4종 배치·3~4개 선택·문구 보존·장문 한글·HTML escaping.
- 전용 Chromium CI: 12개 로고/명함 표시, 비교·선택, 편집·저장·새 탭, 편집→견본 복귀, 360/390/768/1440 가로 넘침.
- 자체 규칙 초안이며 무한 생성·산업별 디자인의 미적 우수성·상표 유사성·인쇄 도련·QR·모든 실기기/접근성 검증 완료가 아니다.
- base는 main 통합 준비 PR #132다. 병합·운영반영·자동 개선 인정은 별도.
