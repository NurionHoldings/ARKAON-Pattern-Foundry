# 디자인 참고 URL 자동 관찰

등록된 제작물의 소유자는 URL별로 기존 참고자료 사용 고지의 다섯 항목을 확인합니다. 서버는 해당 URL·참고 집합의 해시·소유자에 묶인 원칙 참고 동의 영수증을 검사한 후 공개 HTTPS 페이지를 읽습니다.

관찰기는 DNS 결과가 모두 공인 IP인지 확인하고, 확인된 IP로 직접 TLS를 연결하며 호스트 이름으로 인증서를 검증합니다. 리다이렉트와 다른 출처의 스타일시트를 따르지 않습니다. HTML은 최대 512 KiB, 같은 출처 CSS는 파일당 최대 256 KiB·최대 3개로 제한합니다. 요청마다 시간 제한을 둡니다.

추출되는 값은 배경·본문·강조 색상, 구성 유형, 간격 밀도, 원본 내용 해시입니다. 원본 HTML과 CSS는 저장하거나 API 응답에 포함하지 않습니다. 색상 추출은 휴리스틱이므로 사용자는 값을 검토하고 조정한 뒤 자체 CSS 시안을 생성합니다. 실행된 JavaScript, 브라우저 렌더링 결과, 외부 출처 CSS, 인증이 필요한 페이지는 관찰하지 않습니다.

이 단계에서 제안된 스타일은 홈·상세 및 모바일·데스크톱 검토용 화면에서 확인하고 소유자가 적용하거나 거절합니다. 적용은 검토용 미리보기에만 반영되며 운영 배포는 별도 단계입니다. 운영 배포 환경에서는 서버가 공개 HTTPS 목적지로 직접 나갈 수 있어야 자동 관찰이 작동합니다.
