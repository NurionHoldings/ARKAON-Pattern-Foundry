# 제작 전 과정 미리보기 계약 v1

모든 제작물은 입력 → 생성 → 미리보기 → 수정 → 재미리보기 → 선택/승인 → 내보내기의 순서로 진행한다. 미리보기는 해당 사용자·테넌트의 결과물만 보여 주며, 실제 외부 게시·결제·배포 상태를 나타내지 않는다.

| 제작물 | 구현된 미리보기 | 다음 구현에서 필요한 미리보기 |
| --- | --- | --- |
| 로고 | SVG 세 시안, 첨부 PNG/JPEG 원본, 세 가지 움직임 | 참고 이미지와 생성 시안의 나란히 보기·직접 비교, 모바일/밝고 어두운 배경 |
| 명함 | 저장된 앞·뒷면 SVG, 저장 전 입력값으로 만든 임시 앞·뒷면 | 로고 없는 최초 생성과 첨부 명함의 추출 항목 확인, 인쇄 크기 |
| 랜딩페이지 | 저장된 버전의 sandbox iframe, 제목·소개 문구 변경의 저장 전 임시 화면, 모바일·데스크톱 폭 전환 | 단계별 문답을 반영한 임시 버전, 링크·접근성 확인 |
| 플랫폼 설계 | 대화 버전의 SVG 구조 미리보기 | 홈·상세·사용자 흐름을 실제 화면 수준으로 확인하고 승인한 항목만 구현 |

## 공통 동작

1. 미리보기는 현재 입력과 적용한 버전 번호를 표시한다. 저장 전 임시 시안과 저장된 시안을 구분한다.
2. 변경 입력은 먼저 격리된 임시 결과로 보여 준다. 사용자가 저장을 누르면 새 revision을 추가하고 이전 버전을 보존한다.
3. 다운로드·결제·외부 연결·운영 배포는 각각 별도 승인 단계다. 미리보기 또는 초안 저장만으로 실행되지 않는다.
4. 모바일/데스크톱 보기와 움직임 감소 설정을 제공한다. 업로드 원본은 명시된 보관 동의가 없으면 임시 분석 뒤 폐기한다.
5. 이미지 유사성 점수는 시각적 참고 지표일 뿐 권리 침해 여부의 판정이나 복제 허가가 아니다.

로고 애니메이션과 참고 이미지 미리보기는 #063, 명함 저장 전 미리보기는 #064, 랜딩 문구 변경 미리보기는 #065 코드 범위다. '다음 구현' 칸은 아직 완료된 기능으로 표시하지 않는다.
