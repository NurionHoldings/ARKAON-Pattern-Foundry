# 검증용 제작 흐름 체험

`/inspection`은 공개 배포에서 요청·결과물의 예시 미리보기를 살펴보는 별도 체험 화면이다. 운영 계정,
실제 고객 요청, 결제, 제작 엔진, 다운로드 파일 및 배포 작업에 접근하지 않는다.

운영 환경 변수 `APF_DEMO_INSPECTION_ID`에 검증용 아이디를 설정하고,
`APF_DEMO_SESSION_SECRET`에는 추측할 수 없는 32자 이상의 별도 비밀값을 설정한다.
두 값 중 하나라도 누락되면 체험 화면은 404로 비활성화된다. 코드와 공개 저장소에
실제 아이디나 비밀값을 기록하지 않는다.

검증용 아이디가 일치하고 숫자 4자리를 입력하면 30분짜리 체험 쿠키를 발급한다.
어떤 4자리 숫자도 받으므로 이것은 신원 인증 수단이 아니다. 체험 쿠키는 콘솔 세션과
이름·서명 목적이 다르고, 운영 API의 소유자 권한으로 변환되지 않는다.

체험 세션에는 예시 요청과 로고·모바일 명함·소개 페이지의 정적 화면만 보여준다.
입력, 수정, 승인, 제작 실행, 파일 다운로드·인쇄 및 배포 기능을 제공하지 않는다.
실제 제작에 참여하려 하면 회원가입 또는 로그인 및 결제가 필요하다고 안내한다.
현재 회원가입·결제 연동은 연결되지 않았으므로 결제가 가능한 것처럼 표시하지 않는다.

실제 사용자의 회원가입과 제작 요청·결과물 수령을 검증하려면 별도 인증 및
제작 작업 데이터가 연결된 운영 환경에서 종단 간 검사를 통과해야 한다.
