# 13. 외부지식 우선 학습전략

- 명세 ID: APF-EXTERNAL-001
- 원칙: 내부 시스템은 현실 검증용 기준점이고, 외부의 공식 표준·공식 문서·라이선스가 확인된 오픈소스가 발전 학습의 주원료다.

## 학습예산

기본 분석예산은 외부 65%, 내부 35%로 배정한다. 외부자료가 부족하거나 Intent 관련성이 낮으면 비율을 강제로 채우지 않는다. 내부 분석은 누리온의 실제 문제·제약·운영현실을 보존하고, 외부 분석은 새로운 해결구조·표준·실패대응·상호운용성을 공급한다.

## 외부자료 우선순위

1. 국제·산업 공식 표준
2. 제품·프로젝트 공식 문서
3. 라이선스가 명확한 오픈소스 구현과 테스트
4. 검증된 학술논문
5. 공급자 기술사례

블로그·홍보문·출처 재인용문은 발견용 신호로만 사용하고 Pattern의 단독 근거로 사용하지 않는다.

## 초기 외부학습 축

| 학습영역 | 기준 자료 | 획득할 일반구조 |
|---|---|---|
| 출처·라이선스 | SPDX | 라이선스·구성요소·파생관계 표현 |
| 데이터 계보 | OpenLineage | Run/Job/Dataset과 입력·출력 추적 |
| 내구성 작업흐름 | Temporal | 재시도·복구·장기실행·결정성 |
| 정책판정 | Open Policy Agent | 정책과 실행의 분리, deny-by-default |
| 관측성 | OpenTelemetry | trace·metric·log 상관관계 |
| API 계약 | OpenAPI/JSON Schema | 계약 우선 검증과 호환성 |

이는 특정 구현을 복제하라는 뜻이 아니다. 공식 개념과 공개 인터페이스에서 구조 원리를 추출하고 누리온의 Intent_DNA 및 불변조건에 맞춰 독립 구현한다.

## 6단계 분석

DISCOVER → QUALIFY → ROUTE_BY_INTENT → COMPARE → ABSTRACT → VERIFY. 출처는 권위성, Intent 관련성, 라이선스 명확성, 최신성, 새로움으로 점수화한다. 동일 해시는 생략하고, 상위 자료도 Intent 관련성 0.30 미만이면 심층분석하지 않는다.

## 다양성 규칙

하나의 Pattern 후보는 가능하면 서로 독립적인 외부 근거 2개와 내부 적용사례 1개로 삼각검증한다. 단일 공급자의 용어·제약을 범용 사실로 오인하지 않는다. 상충하는 표준이나 구현은 숨기지 않고 Trade-off로 기록한다.

## 발전 루프

외부 신규구조 발견 → 기존 Intent_DNA와 충돌검사 → 합성 실험 → 내부 플랫폼 shadow 적용 → 검증 → 승인 → Package 출시 → 실제 재사용 결과 축적. 실패한 접근도 AntiPattern으로 저장해 반복 비용을 줄인다.

## 금지

무단 크롤링, robots/이용조건 위반, 인증 우회, 비공개 코드 취득, 디자인·문구 복제, 라이선스 미확인 코드 혼입, 고객자료를 외부 서비스로 전송하는 행위를 금지한다.
