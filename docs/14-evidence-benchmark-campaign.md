# #026 증거 기반 실전 벤치마크 캠페인

## 판정 원칙

ARKAON의 자기보고 수치는 완료 증거로 사용하지 않는다. 에테르니언이 관측한 시간,
개입 횟수와 Worker Runtime의 실행 영수증을 결합하고, 원문을 포함하지 않는
`evidence://sha256/...` 참조를 요구한다.

## 비교 설계

- BASELINE과 CURRENT는 동일한 scenario_id와 역할로 정확히 짝을 이룬다.
- 하나의 실행 영수증은 한 번만 사용할 수 있다.
- 다섯 역할(RESEARCH, ARCHITECT, BUILD, TEST, AUDIT)을 모두 측정한다.
- 시간은 시간대가 있는 시작·종료 시각으로 계산한다.
- 성공 여부와 범위 위반은 실행 영수증에서 파생한다.
- Intent_DNA 일치도와 개입 횟수는 에테르니언 관측값만 허용한다.
- 평가 후 캠페인은 봉인되어 결과를 사후 변경할 수 없다.

## 완료 조건

#025의 기본 게이트를 그대로 적용한다. 역할별 성공률 90%, Intent_DNA 일치도 95%,
에테르니언 개입 50% 감소, 안전 위반 0건 중 하나라도 실패하면 캠페인은 통과하지 못한다.
