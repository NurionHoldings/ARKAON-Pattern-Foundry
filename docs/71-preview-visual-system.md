# ARKAON 미리보기 디자인 체계 v1

## 목표

로고·명함·랜딩·플랫폼 제작 도구의 작업 UI와 결과물을 구분한다. 이번 단계는 **결과물 미리보기**의 공통 시각 언어를 먼저 구현한다. 운영 콘솔과 제작 도구 UI의 전체 교체는 후속 범위다.

## 공통 토큰

`src/apf/preview_design.py`의 `FOUNDATION_CSS`를 랜딩과 플랫폼 시안에 함께 적용한다.

| 토큰 | 역할 |
| --- | --- |
| night / deep | 아르카온의 짙은 남색, 헤더와 첫 화면 |
| paper / surface | 따뜻한 종이색 바탕과 읽기 영역 |
| mint / mint-bright | 주요 행동과 단계 강조 |
| amber | 보조 시각 강조 |
| ink / muted / line | 본문, 보조 문장, 구분선 |

외부 글꼴·이미지·스크립트를 가져오지 않는다. 생성 HTML의 사용자 문구는 서버에서 이스케이프한다. CSS 장식은 데이터나 이미지 결과물로 가장하지 않도록 `aria-hidden` 또는 자리 표시 문구를 사용한다.

## 화면별 차이

- 랜딩: 문장을 중심으로 한 편집형 첫 화면, 장식적인 원형 그래픽, 변경점과 다음 단계의 두 구획.
- 플랫폼 홈: 가치 제안과 핵심 구성요소가 먼저 보이는 첫 화면.
- 플랫폼 상세: 이미지 자리와 목적 설명이 나란히 놓이고, 그 아래에 상세 구성요소가 나타나는 화면.
- 상세 명세가 하나뿐이면 실제로 없는 내용을 만들어 내지 않고 미작성 상태를 표시한다.

## 수용 기준

1. 390px, 768px, 1440px 미리보기에서 가로 스크롤이 없고 글자가 겹치지 않는다.
2. 저장 전 시안과 저장된 revision은 같은 디자인 CSS를 사용한다.
3. 움직임 감소 설정에서 장식 애니메이션이 정지한다.
4. 키보드 초점이 보이며 텍스트와 주요 행동의 명암 대비를 실제 브라우저에서 확인한다.
5. 홈과 상세는 제목만 바꾼 동일한 화면이 아닌 서로 다른 정보 배치를 쓴다.
6. CI는 HTML 이스케이프, CSS 계약, 저장소 소유권, 기존 회귀시험을 확인한다. 실제 브라우저 캡처 비교는 별도 시각 검증 단계에서 수행한다.
