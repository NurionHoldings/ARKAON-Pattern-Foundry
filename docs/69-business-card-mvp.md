# 69. 명함 SVG MVP

- 변경 ID: `060-business-card`
- 상태: OWNER_REVIEW_REQUIRED

저장된 `logo_svg` 초안 중 현재 tenant와 owner에 속한 항목만 선택해 명함을 만든다. 명함은 앞면과 뒷면 SVG 한 쌍이며, 이름·직함·전화·이메일·브랜드 텍스트를 XML 1.0 허용 문자로 제한하고 이스케이프하여 삽입한다.

## 흐름

`저장 로고 선택 → 연락처 입력 → 앞·뒤 미리보기 → 수정 revision → rollback → 각 면 SVG 다운로드`

각 수정과 복원은 최신 `revision_digest`가 있어야 한다. 생성 시 선택한 로고의 digest 검증된 최신 SVG에서 로고 마크를 다시 그리므로 다른 tenant·owner의 로고를 참조할 수 없다. 연락처는 Git 저장소에 넣지 않고 테넌트 소유의 런타임 상태 파일에만 평문으로 저장한다. 기본 경로는 암호화되지 않은 임시 디렉터리여서 재시작·정리 과정에서 사라질 수 있다. 이 MVP에는 암호화·백업·보존 기간·삭제 자동화가 없으며, 운영 환경에서는 `APF_RUNTIME_ROOT`를 접근 제어된 전용 저장소로 반드시 지정하고 별도 보존·백업 정책을 적용해야 한다.

## 경계

결과물은 결정적인 도형·텍스트 SVG이다. 이미지 모델, 외부 API, 이메일·SMS, 외부 저장소 쓰기, 배포는 수행하지 않는다. 크레딧 상한은 500이며, 소비 계량기는 제공되지 않는다.
