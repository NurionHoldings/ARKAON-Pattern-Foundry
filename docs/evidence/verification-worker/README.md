자동 시험 작업자 실행 성공은 아르카온의 자율 코드 구현·전체 1차 검증·독립 감사·병합·배포 완료가 아니다. Windows 사용자 PC 설치와 relay 재시작은 아직 수행하지 않았다. GitHub Actions의 원장은 실행별 임시 저장소이며 운영의 실행 간 영속 원장은 PC의 지속 보관 경로가 필요하다.
