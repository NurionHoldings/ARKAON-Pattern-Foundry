VIS-01(흰색 로고가 흰 배경에서 사라짐), UX-01(은(는)/을(를) 미완성 조사).
이 구현은 에테르니언 직접 보완이다. ARKAON 자동 구현·1차 검증 또는 모델 가중치 학습으로 표시하지 않는다.

- 흰 브랜드색은 보존하고 미리보기·회사 명함 로고 영역·6개 후보에 읽을 수 있는 배경을 선택한다.
- 로고 배경 비교의 기존 흰색/단색 대안과 안내를 유지한다. 자체 가독성 기준은 대비 4.5이며 법적 인증이 아니다.
- 소개는 입력한 업종·상호·고객·서비스·강점만 사용한다. 미확인 인증/실적/가격을 만들거나 사용자 편집 문구를 덮지 않는다.
