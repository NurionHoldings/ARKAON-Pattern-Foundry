# 69. 이름@ 개인 페이지 독립 코어

`apf.name_at`는 승인된 프로필만 게시·검색 가능한 독립 코어다. 이미지 참조는 최대 3개,
영상 참조는 1개다. 실제 파일 업로드·영상 변환·공개 HTML/API·외부 인증은 아직 연결되지
않았고 운영 기능으로 표시해서는 안 된다. 저장소는 승인된 외부 URL의 참조만 다룬다.

호스트 애플리케이션이 인증된 tenant/owner를 전달하고 승인 화면이 초안 digest를 소유자에게
보여줘야 한다. 이름은 사람별로 독점하지 않으며 `이름@` 조회에서 동명이인을 모두 반환한다.
수정 초안은 다시 승인받아야 하며 철회 즉시 내부 검색·사이트맵에서 빠진다.

게시 결과의 검색 통지 계획은 네이버·빙 IndexNow, 구글 사이트맵, 다음 사이트 등록 심사를
구분한다. `discovery_jobs`는 전달할 작업을 생성할 뿐 네트워크 제출이나 수집·색인·순위
확인을 수행하지 않는다. 플랫폼 도메인의 소유 확인과 검색 도구 연결은 운영자가 별도로
완료해야 한다. 엔진별 접수, 수집, 색인, `이름@` 최상단 노출을 각각 기록해야 한다.

다음 구현 순서: 인증된 라우터와 HTML 렌더러 → 안전한 미디어 업로드/삭제 → 사이트맵
공개 → 공식 계정 소유 확인 → IndexNow 작업자·Search Console 연결 → 다음 신청 안내·
상태 확인 → 실제 검색 결과 실험. 기존 `PRODUCT_IMPLEMENT_HOLD`는 유지한다.
