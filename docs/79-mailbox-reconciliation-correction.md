## 정정

- 원본 누락은 이행 완료 증거가 아니다. PENDING을 보존하고 payload_missing으로 보고한다.
- 전송 패킷 아카이브도 작업 완료 증거가 아니다. PENDING을 보존한다.
- 날짜/단계/상대경로가 일치하는 아카이브만 전송 보관 근거로 기록한다.
  다른 단계의 동명 파일은 인정하지 않는다.
- inbox 밖 경로·부모 경로 탈출·절대경로는 완료 판정에 사용하지 않는다.
- COMPLETED fulfillment와 item_id가 일치하는 기존 명시적 이행 경로는 유지한다.
- 통합 우편함도 비 UTF-8 및 객체가 아닌 JSON을 건너뛰고 정상 패킷을 계속 동기화한다.
  손상 원본은 이동하거나 삭제하지 않는다.

자동 승인·구현·병합·배포 권한을 추가하지 않는다. 과거 FULFILLED 기록은 이 정정에서
일괄 변경하지 않는다. 실제 원장과 이행 증거를 대조한 뒤 별도로 판단해야 한다.
