# 15. 검증된 선례 우선 자산화 전략

- 명세 ID: APF-PRECEDENT-001
- 상태: LOCKED DEFAULT

늦게 출발한 비용은 이미 검증된 선례를 빠르게 학습해 줄인다. 신규 기능을 백지에서 설계하지
않고, 요구 기능마다 권위성·운영성숙도·실패대응·상호운용성·Intent 관련성이 검증된 선례를
먼저 확보한다. 적합한 선례가 없는 기능은 독립설계 Gate를 통과하지 않는다.

선례에서 반드시 추출하는 대상은 기능 목적, 인터페이스, 실패모드, 복구방식, 테스트 가능한
완료기준이다. 상표·문구·화면표현·비공개 구현·원본 코드는 복제하지 않는다.

자산화 흐름은 `BENCHMARK → COMPARE → ABSTRACT → INDEPENDENT DESIGN → BUILD → VERIFY →
OWNED ASSET`이다. 동일 계열의 반복 자료로 신뢰도를 부풀리지 않고, 가능한 경우 독립된 표준과
운영 구현을 함께 대조한다. 최종 산출물은 누리온의 Intent_DNA, 권한경계, 상태모델과 테스트에
맞춘 자체 구현이어야 한다.
