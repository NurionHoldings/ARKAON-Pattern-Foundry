# 해온 업무 프로그램 생성

`/console/care-operations`에서 사무/회계/요양급여 검토/식자재 수불/기타 재고를 선택하고 구성과 검증 규칙을 확인한다. 같은 구성 해시를 확인한 경우에만 서버가 독립 실행 HTML을 생성한다. API는 `/v1/console/care-operations/program`이며 기존 콘솔 인증·CSRF·owner/operator/reviewer 역할이 필요하다.

생성 HTML은 사무 기록, 수입/지출 합계, 수기요율 급여 산술 초안, 로트별 재고 수불 및 잔량을 실제 실행한다. 데이터는 열린 창의 메모리에만 남고 명시적으로 JSON 내보내기가 가능하다. 서버 인증이나 지속 저장이 없는 프로그램 미리보기이며 민감정보를 입력하지 않는다. 구성이 달라지면 이전 확인 해시는 무효다. 브랜드 문자열은 HTML 스크립트 탈출을 차단해 삽입한다.

실운영 저장과 층별 로그인은 별도 thearirang 프로젝트에 구현했다. Foundry는 이 기능을 통해 프롬프트만 전달하는 대신 실행 가능한 프로그램을 만들지만, 모델 가중치 학습·운영 배포·실데이터 수집·세무신고·공단 제출은 하지 않는다. `PRODUCT_IMPLEMENT_HOLD` 및 기존 운영 변경/승격 정책은 유지한다.

수기 일당과 부담률은 공단 법정 요율이 자동 검증된 값이 아니다. 기관/급여유형/적용일별 요율 근거와 공단 인터페이스, 정정/취소/승인/백업은 실운영 통합 시 추가 검토한다.
