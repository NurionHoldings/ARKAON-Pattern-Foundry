# 마컬(My Coloring) 제품 기준 및 SKT 공동 실증 자산

## 확정된 제품 동선

1. 상대가 내명함을 **한 번** 클릭하여 프로필을 본다.
2. 이후 별도 앱 설치, 가입, 권한 허용, 기본 전화 앱 교체, 알림·문자 터치 없이 자신의 기본 전화 앱으로 저장된 기존 010 번호에 발신한다.
3. 지원 가능한 실제 단말에서 수신자가 공개 승인한 마컬 화면이 자동으로 나타난다. 통화 연결 후에도 용건 메뉴가 유지된다.
4. 상대가 메뉴를 선택하면 수신자 화면에도 같은 메뉴가 열리고, 통화 요청은 수신자가 결정한다.

명함 링크 열람은 번호·템플릿 표시의 계기일 뿐, 웹사이트가 향후 일반 전화 앱 발신을 감시하거나 자동 실행 권한을 설치하는 행위가 아니다. 이 클릭만으로 자동 실행이 가능하다는 기술적 증거는 아직 없다. SDK 설치, 전화 식별 앱 역할 승인, 앱 내 전화 버튼, 수동 URL/알림 터치는 이 제품 조건에 불합격이다.

## SK텔레콤 접목 후보와 검증 질문

| 후보 | 확인된 기능 | 요청할 확장·실증 |
| --- | --- | --- |
| V 컬러링 | 수신자가 설정한 영상이 지원 전화 앱의 발신 대기 화면에 나타남 | 클릭 가능한 템플릿, 통화 연결 후 화면 지속, 번호·세션 매핑 인터페이스 |
| T ARS | 기존 010 번호 자동 응답, 1~10개 음성 메뉴와 MMS 안내 | 웹 메뉴 진입 및 일반 음성통화 연결을 양측 화면 세션과 함께 조정할 방법 |
| 에이닷 전화 | 비즈연락처 등 전화 앱 접점 | 개인 번호 등록 가능 여부, 수신자 지정 콘텐츠와 메뉴 표시 가능 여부 |

V 컬러링의 **동영상 표시**를 웹 메뉴 실행 또는 통화 후 화면 유지가 이미 제공된다는 뜻으로 해석하지 않는다. 지원 전화 앱, 단말, HD Voice, 통신사 조건에 따라 표시율이 달라지므로 대상 범위를 기록한다. T ARS의 MMS 수신은 브라우저 자동 실행의 증거가 아니다.

## 실증 순서

1. 등록 010 수신 번호에 V 컬러링을 설정하고 별도 준비를 하지 않은 두 번째 안드로이드폰의 기본 전화 앱에서 발신한다. 지원 조건·발신자 화면 표시율·표시 시점·통화 연결 후 종료 시점을 촬영·기록한다.
2. SKT에 발신 화면 확장 API, 통화 중 양방향 화면 데이터 채널, 발신·수신 번호별 등록, 통신사 간 및 OEM 호환, 테스트 환경 제공 여부를 요청한다.
3. 지원 인터페이스가 확보되면 개인 템플릿을 전화 번호에 매핑하고, 양측이 메뉴를 동시에 보는지 실제 회선으로 검증한다.

`apf.macol_readiness.assess_macol_trial`은 이 증거를 판정한다. `PASS`도 **실험한 단말·망 조합에 한정**되며, 전 발신자 지원을 뜻하지 않는다. 현재 알려진 결과는 일반 음성통화 성공, 010 발신자 자동 화면 표시 실패이므로 제품은 아직 FAIL이다. 개인 번호는 공개 산출물에 적지 않는다.
