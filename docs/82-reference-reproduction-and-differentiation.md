# 참고자료 재현과 차별화 제안

사용자 소유·허가·라이선스 등 권리 근거와 증거가 있는 직접 재사용 경로를 유지한다.
책임 동의만으로 권리 불명확 자료의 직접 복제를 허용하지 않는다.
민사·형사 책임은 행위와 법정 요건에 따라 판단되며 고지로 전부 이전되지 않는다.
고지 1.1은 새 이해 확인을 요구한다. 과거 receipt는 덮어쓰거나 소급 변경하지 않는다.

판정 응답과 기존 동의 화면에 브랜드, 미디어, 문구, 정보 구조, 이용 흐름, 코드/폰트
조건의 구체적 수정 범위를 제안한다. 색상·애니메이션·변경 비율에 법적 안전 보장을
부여하지 않는다. 제안은 일반 체크리스트이며 자료별 유사성 분석이나 자동 변환이 아니다.
수정 범위를 바꾸면 새 request와 digest에 결속한 승인이 필요하다.

기존 직접 재사용의 reason은 증거 hash의 존재만 검사하면서 VERIFIED라고 표시했다.
독립된 권리 검증이 구현된 것으로 오해하지 않도록 RECORDED로 정정한다.
자동 복제 실행기·병합·배포 권한을 추가하지 않는다.
