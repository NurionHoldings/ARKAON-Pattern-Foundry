# 다판다·더아리랑 기본 틀

사용자의 지정에 따라 공개 화면의 배경색·배치를 관찰하고 자체 렌더러로 구현한다.
홈페이지 만들기 → 2 분위기에서 기존 3종과 함께 두 기본 틀을 선택할 수 있다.
같은 내용을 유지한 채 배치·색상을 바꾸며 로컬 저장/재오픈 시 theme을 보존한다.
`?foundation=dapanda` 또는 `?foundation=arirang`으로도 기본 선택을 지정할 수 있다.
기존 project/session 초안이 있으면 저장된 초안을 우선한다.
`APFStudio.foundationPresets`와 `compose/render`를 통해 향후 플랫폼 생성도 같은 틀을 사용할 수 있다.
이번 범위는 화면 기본 틀이며 거래·예약·회원·운영 플랫폼 자동 개설 실행기는 아니다.
