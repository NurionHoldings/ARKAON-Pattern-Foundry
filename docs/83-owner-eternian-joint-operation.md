# 자동 관측과 요청 기반 추가 조사의 공동 운영

2026-11-08 사용자 지시를 반영한 설계·초안이다. PC가 켜진 동안의 자동 학습 준비는 허용하고,
제품 수정은 에테르니언의 보고 후 사용자 지시에 따라 함께 수행한다.

## 두 경로

| 경로 | 작동 시점 | 범위 | 결과 | 제품 변경 |
| --- | --- | --- | --- | --- |
| 자동 관측·학습 준비 | 로컬 PC 시작 후 기존 collector 예약 작업 | 허용 목록·시간대별 주제 | 수집 판정·출처·해시·중복 기록 | 없음 |
| 수동 추가 조사 | 사용자가 필요한 기능을 요청하고 에테르니언과 진행 | 요청 주제와 명시한 허용 출처 | 해당 회차 조사 기록·에테르니언 분석 보고 | 별도 수정 지시 후 |

기존 collector.default.json의 enabled=true, OS_BOOT, collect_immediately=true,
900초 간격은 유지한다. 자동 수집을 끄는 준비안은 커밋·운영 적용하지 않았다.
자동 실행은 실제 PC의 예약 작업 설치·업데이트·실행 상태에 의존하며 이 세션에서 검증하지 않았다.

현재 collector의 collected 카운터는 자료를 가져와 해시·판정을 기록했다는 의미다.
자료의 깊은 이해, 영속 원문 학습, 모델 재훈련, 신규 기능 코딩 또는 성능 향상을
입증하지 않는다. 요약·교훈 생성·실제 작업 연결·평가 통과는 각각 별도 실행 증거가 필요하다.

## 수동 추가 조사 구현

`apf.collector_service --once --manual-topic TOPIC --source-id APPROVED_ID`.
source-id는 반복 가능하고 기존 허용 목록의 항목만 선택한다. 허용되지 않은 출처를 임의로
공식 자료로 승격하지 않는다. 주제는 1~200자이며 비밀정보·개인정보·알려진 인젝션 지시를
검사한다. 수동 조사는 시간대별 주제 필터만 생략하며 권한·HTTPS·민감자료 차단·중복 검사는
유지한다. 기본 수집 설정을 변경하지 않고 회차별 결과를 state/manual-learning에 기록한다.
동일 자료를 이미 수집했다면 중복으로 보고하고 실제 새 학습으로 계산하지 않는다.

이 명령은 인터넷 검색엔진이 아니다. 새로운 출처를 찾는 개방형 검색은 사용자의 요청에 따라
에테르니언의 연결된 검색 도구로 수행하고, 권리·출처를 검토한 뒤 별도 승인 범위로 다룬다.
새 수동 조사 CLI는 PC에 업데이트 후 사용할 수 있으며 PC 원격 실행·서버 연결을 생성하지 않는다.

## 보고와 수정

1. 자동 관측으로 쌓인 자료나 요청에 따른 추가 조사 내용을 에테르니언과 검토한다.
2. 원인·근거·추가 기능의 필요성·영향·위험·권고안을 사용자에게 보고한다.
3. 사용자의 수정 지시에 따라 제한된 범위에서 구현·검증하고 결과를 보고한다.
4. 읽기 요청은 수정·학습 승격·아카이브·실행·병합·배포 승인이 아니다.
   이미 구체적으로 지시한 동일 범위의 승인을 반복 요구하지 않는다.

## 우편함의 요청 시 열람

공개 홈페이지와 내부 우편함 데이터는 별개다. HTTPS Foundry API 주소와 정상 인증 연결을
최초 설정해야 에테르니언이 요청 시 실제 우편함에 접근할 수 있다. 브라우저에 주소를 저장하는
것만으로 ChatGPT 접근 권한이 생기지 않는다. 내부 자료를 공개 저장소로 옮기지 않는다.
세션 만료·서버 중단 시 연결 상태를 보고하고 0건으로 오인하지 않는다. 연결 완료·24시간
가용성·실제 worker ACK는 이 초안의 검증 범위가 아니다.
