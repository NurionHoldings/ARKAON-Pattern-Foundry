# 참고자료 사용자 요청·책임 고지 v1

참고자료도 학습·설계 자산의 일부로 취급한다. 사용자가 특정 자료의 사용을 요청하면 목적과
범위를 기록하고 고지사항을 모두 확인한 뒤 분석 또는 sandbox 구현을 진행할 수 있다.

## 선택 화면 고지

> 사용자가 지정·제공한 참고자료와 권리 주장에 관한 귀책사유가 있으면 사용자가 그 책임을
> 부담할 수 있습니다. 이 확인은 무단 이용을 적법하게 만들거나 플랫폼의 책임을 전부
> 사용자에게 이전하지 않습니다. 권리가 불명확하거나 침해 가능성이 높으면 구현을 거절하거나
> 격리할 수 있으며, 이 확인은 병합·배포 승인이 아닙니다.

사용자는 다음 다섯 항목을 모두 개별 체크한다.

1. 내가 이 자료의 구체적인 사용을 요청했다.
2. 내가 제공한 자료와 권리 주장의 정확성에 관한 귀책 책임을 이해한다.
3. 이 확인만으로 허가되지 않은 이용이 적법해지는 것은 아님을 이해한다.
4. 시스템이 침해 가능성이 높은 요청을 거절·격리할 수 있음을 이해한다.
5. 이 확인은 병합·운영 배포 승인이 아님을 이해한다.

## 허용 범위

- `PRINCIPLE_REFERENCE`: 기능 목적과 일반 원리를 분석한다. 구현 권한은 주지 않는다.
- `CLEAN_ROOM_IMPLEMENTATION`: 원본 표현을 사용하지 않는 독립 sandbox 구현을 허용한다.
- `DIRECT_REUSE`: 소유권·라이선스·명시적 허가와 SHA-256 권리 증거가 있을 때만 허용한다.

사용자 체크만 있는 `DIRECT_REUSE`는 차단한다. 개인정보·비밀자료·접근통제 우회 자료도
동의 여부와 관계없이 차단한다. 모든 동의는 요청·자료·용도·경로·scope digest·고지문 버전·
사용자·시각·nonce에 결속해 원장에 한 번만 기록한다.

저작권법상 저작자에게 복제권과 공중송신권 등이 있으므로 책임 고지만으로 이용허락을
대체하지 않는다. 구체적인 분쟁 가능성이 있는 경우 법률전문가의 검토 대상으로 `HOLD`한다.
