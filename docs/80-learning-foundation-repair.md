# 지속학습 근본 개선: 1차 구현과 다음 합격 기준

## 확인한 결함과 구현

LearningMemory는 dict에만 저장했고 from_foundry도 교훈을 복구하지 않았다.
LearningAccelerator도 기본 생성 시 휘발성 메모리를 사용한다.
따라서 이 코드 경로의 재시작 후 누적 교훈 재사용은 보장되지 않았다.

from_foundry를 SQLite 영속 메모리로 연결하고 LearningAccelerator.from_foundry를
명시적 진입점으로 추가한다. 기본 생성자는 일시 메모리 용도로 유지한다.
state/learning-memory.sqlite3은 Git에서 제외한다. 매 작업은 트랜잭션 안에서
최신 기록을 읽어 오래된 인스턴스의 덮어쓰기를 방지한다. 교훈 identity와 content
SHA-256을 재검증하고 손상은 오류로 차단한다. 신뢰도·검증·근거·중복·강화·실패군
한도 및 intent/domain 제한을 유지한다.

체크섬은 서명이나 독립 감사가 아니다. 로컬 DB 쓰기 권한은 신뢰 경계다.
검증 서비스 nonce 소비 기록과 accelerator 실행 중 상태는 아직 메모리 기반이다.
이 PR은 승인 replay 방지 영속화나 전체 작업 복구를 구현했다고 주장하지 않는다.
운영 worker 일괄 전환이나 과거 교훈 자동 승인·이관은 포함하지 않는다.

## 근본 개선 단계별 합격 기준

1. 실행 관측: 회차 시작·종료·오류·실행 SHA·수집/탈락 수를 기록한다.
   24시간 예정 회차와 실제 회차를 대조하고 사유 없는 공백을 실패로 판정한다.
2. 실제 재사용: 승인된 worker 한 종류부터 영속 진입점을 연결한다.
   작업 입력에 교훈 hash와 intent를 묶고 재시작 후 조회를 입증한다.
   교훈이 없으면 근거 부족으로 보고한다.
3. 성과 평가: 과제와 채점기를 먼저 고정한다. 학습자료와 분리한 미공개 과제
   20개 이상에 동일 입력·환경·예산으로 기준선과 교훈 사용 결과를 비교한다.
   과제별 성공·실패·비용·시간·출력 hash를 남긴다. 수집량과 자기평가는 성과가 아니다.
4. 승격: 안전 필수 과제 실패 0, 기존 통과 과제 회귀 0, 목표 실패 감소 및 실제
   재사용 증거가 모두 있어야 독립 검토를 요청한다. 비용·시간 한도는 사전 확정한다.
5. 환류: 실패를 원인별 후보로 만들고 독립 검토·범위 승인·결과 비교 후 적용한다.
   악화 시 이전 승인 교훈 집합으로 복구할 수 있도록 활성 집합과 버전을 관리한다.

## 현재 판정과 롤백

이는 저장·재조회 기반 개선이다. 실제 과제 정확도 향상, 모델 가중치 학습,
24시간 자율학습, 운영 worker 연결, ARKAON/ETERNIAN 이중 검증 완료를 뜻하지 않는다.
합성 교훈으로 재시작 복구·중복·강화·손상 차단을 시험한다.
운영 활성화 전 DB 백업·로컬 접근 통제·단일 호스트 저장 경로 및 승인 기록 영속화를
점검한다. 자동 승인·병합·배포는 추가하지 않는다.
롤백은 본 PR revert이며 생성 DB는 지우지 않고 보존한다.
