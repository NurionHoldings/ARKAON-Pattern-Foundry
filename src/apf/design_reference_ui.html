디자인 참고 URL

마음에 드는 사이트 주소를 3~4개씩 모아주세요. 저장 후 다음 묶음을 계속 입력할 수 있습니다.

참고자료 사용 범위

공개 화면의 색상·간격·구성 원리를 관찰해 새로운 시안을 만드는 용도입니다. URL 등록만으로 원본 CSS를 복사하거나 운영 화면에 적용하지 않습니다. 별도 분석과 사용자 미리보기 확인이 필요합니다.

로그인이 필요한 페이지, 개인정보가 담긴 주소, 비공개 자료 주소는 입력하지 마세요. HTTPS 공개 페이지 주소만 받습니다.

주소 입력

등록된 참고 주소

  1. 불러오는 중입니다.

상태: 주소 등록 · 디자인 분석 및 CSS 적용 전

공개 화면 관찰값 → 자체 CSS 시안

등록한 공개 페이지를 직접 확인하고 색상과 구성만 기록하세요. 원본 CSS나 이미지 파일은 이 입력창으로 수집하지 않습니다. 여러 참고 URL의 관찰값을 합쳐 ARKAON 자체 규칙으로 시안을 생성합니다.

자동 관찰 전 확인

공개 HTTPS의 정적 HTML과 같은 사이트의 CSS만 읽습니다. 로그인 화면, 실행된 스크립트의 화면, 외부 스타일 파일은 분석하지 않습니다.

미리보기와 적용 결정

시안 적용은 이 제작물의 검토용 화면에만 반영됩니다. 운영 배포는 별도입니다.
