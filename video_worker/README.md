# ARKAON 자체 GPU 영상 생성기 — 1차 안전 기반

외부 **영상 생성 API** 없이 자체 관리 GPU에서 오픈소스 모델을 실행하기 위한 독립 워커의 최소 골격입니다. **현재 실제 MP4 생성 기능은 구현되지 않았습니다.**

## 운영 원칙
- 첫 실험은 월 5만~10만 원 예산 내에서 승인 후 수행
- GPU는 작업이 있을 때만 시작하고 종료. 인스턴스·스토리지·전송 비용은 별도 확인
- API는 사설 네트워크에만 바인딩하고 `ARKAON_WORKER_TOKEN`을 서버 비밀로 관리
- 기본값은 생성 비활성화. 모델·대기열·저장소·과금 제한·실패 처리 검증 전에는 공개 배포 금지
- 사용자의 원본 이미지는 별도 접근 통제 및 삭제 정책 적용

## 로컬 제어부 시험
```bash
python -m venv .venv
. .venv/bin/activate
pip install -r video_worker/requirements.txt
ARKAON_WORKER_TOKEN=local-test-token uvicorn video_worker.app:app --host 127.0.0.1 --port 8765
```
`GET /health`는 준비 상태를 보여주며, `POST /jobs`는 의도적으로 503/501을 반환합니다. 영상 생성 성공을 가장하지 않습니다.
