# ARKAON 살아있는 공존의 눈

이 구현은 아르카온의 **인간 홍채 × AI 반도체** 디자인을 위한 실제 작동하는 정적 HTML/CSS/JS 애니메이션 모듈입니다.

## 구성
- CSS 홍채 수축·확장, 공전하는 회로 궤도, 유영하는 눈, 빛 변화
- 사용자가 클릭하여 깨어남/휴식 상태를 전환
- 움직임 일시정지 제어 및 `prefers-reduced-motion` 지원
- 반응형 레이아웃과 접근 가능한 버튼
- 서비스 홈 이동 버튼

## 통합
`experiences/living-eye/index.html`을 정적 사이트에 포함해 `/experiences/living-eye/` 경로로 게시합니다. 현재 루트 `index.html`을 덮어쓰지 않으므로 기존 홈페이지를 유지합니다.

**중요:** 이전 대화에서 생성된 포토리얼 이미지 원본은 GitHub에 업로드되지 않았습니다. 이 버전은 이미지 없이 CSS로 구현한 독립 동작 데모이며, 최종 이미지의 픽셀 정합 오버레이나 이미지 기반 홍채 추적 효과는 아직 구현되지 않았습니다. 정식 적용 시 승인된 원본 이미지를 저장소에 넣고 실제 이미지에 맞춰 레이어 위치를 조정해야 합니다.

외부 AI 서비스나 GPU, 마이크 접근, 사용자 데이터 수집은 없습니다. 운영 공개 전 브라우저·모바일·접근성 검증이 필요합니다.
