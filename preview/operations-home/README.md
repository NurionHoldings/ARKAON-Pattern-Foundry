# ARKAON 운영 홈 미리보기

`index.html`은 단독 정적 페이지로 배포할 수 있는 운영 홈 UI 미리보기입니다. 모든 메뉴는 실제 서비스 상태를 오해하지 않도록 검증 대기 표시를 포함합니다.

Netlify에 이 경로를 publish directory로 설정하면 별도 프리뷰 사이트에서 확인할 수 있습니다. 기존 운영 사이트의 publish directory를 변경하면 다른 경로가 사라질 수 있으므로, 기존 사이트에 바로 적용하지 말고 **별도 Preview/Deploy Preview**로 검증하세요.

현재 GitHub 커밋만으로 Netlify 배포가 자동 실행되는 것은 확인되지 않았습니다. 배포 후 실제 URL/브라우저 점검이 필요합니다.
