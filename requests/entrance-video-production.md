# ARKAON 진입 영상 제작 실행 지시서

## 목적
ARKAON 진입 화면에 사용할 6~8초 길이의 16:9 시네마틱 무음 루프 영상을 제작한다. 상징은 **인간과 AI의 공존**이다. 사용자가 승인한 디자인 방향은 **실제 인간 홍채 + 홍채 외부의 반도체 회로와 AI 구조물**이며, 다크 네이비·아이스 블루·은빛·은은한 골드로 표현한다.

## 제작 순서
1. 이미지 원본의 사용 가능 여부와 경로를 확인한다. 이미지가 저장소에 없으면 임의로 다른 이미지를 승인된 원본이라고 주장하지 말고 **ASSET_MISSING**으로 기록한다.
2. 자체 GPU/영상 추론 모델이 실제 연결되어 있는지 확인한다. 모델이 없으면 **MODEL_UNAVAILABLE**로 중단하고 가짜 MP4나 성공 보고를 만들지 않는다.
3. 모델이 연결되면 1280×720, 24fps, 6~8초, H.264 MP4(웹 재생 호환), 무음, 자연스러운 루프를 목표로 생성한다.
4. 움직임: 0~2초 암전에서 홍채가 서서히 드러남 → 2~4초 미세한 홍채 수축·확장과 반도체 회로의 순차 점등 → 4~6초 회로 궤도와 빛의 흐름이 인간 홍채에 부드럽게 수렴 → 마지막 1~2초 안정된 눈과 ARKAON 워드마크.
5. 눈을 과장되게 깜박이거나 불쾌한 얼굴 왜곡, 번쩍이는 섬광, 과도한 카메라 흔들림, 읽기 어려운 텍스트를 만들지 않는다.
6. 생성 결과를 브라우저에서 확인하고 PC/모바일, 자동재생 정책(음소거·playsinline), 정지 이미지 폴백, reduced-motion을 검증한다.
7. 실제 출력물이 있을 때만 경로·해시·재생시간·해상도·코덱·제작 비용을 기록한다. 실운영 배포는 별도 승인 게이트를 통과한 뒤 진행한다.

## 실행 제한
- 승인 없는 유료 GPU 대여, API 호출, 결제 및 공개 배포 금지
- 외부 인물 사진·음성·저작권 불명 자산 사용 금지
- 현재 이미지 생성 대화의 바이너리는 저장소에 자동 반영되지 않음
- 최종 영상이 없다면 '영상 생성 완료'라고 보고하지 말 것
